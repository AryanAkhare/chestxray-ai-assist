# Intended use

Research and educational tool that displays the output of machine-learning models trained on the public NIH ChestX-ray14 dataset. It is not a medical device, does not provide a diagnosis, and must not be used to make or delay clinical decisions. All outputs require review by a qualified clinician.

This software is a research prototype. It is not cleared or approved by any regulator, and no external or clinical evaluation has been performed. Outputs are model scores, not calibrated probabilities. The tool does not finalize a report or replace a qualified review.
